# Component Examples

This folder contains example usage files for various components. These files demonstrate how to use the components with sample data and different configurations.

## Files

### ClueList.example.tsx
Example usage of the `ClueList` component showing how to display a list of crossword clues with different states (solved, current, etc.).

### CluePanel.example.tsx
Example usage of the `CluePanel` component demonstrating the full clue panel with across/down clues, filtering, and interaction patterns.

### CrosswordGrid.example.tsx
Example usage of the `CrosswordGrid` component showing how to render a crossword grid with cells, numbers, and user input.

### SolvingControls.example.tsx
Example usage of the `SolvingControls` component demonstrating the control panel for puzzle solving actions (check, reveal, clear, etc.).

## Purpose

These example files serve as:
- **Documentation**: Show how to use components with real data
- **Development**: Quick reference during component development
- **Testing**: Manual testing scenarios with various data states
- **Storybook Alternative**: Lightweight examples without additional tooling

## Usage

These files are not imported into the main application. They are reference files for developers working on the components.

To view an example:
1. Temporarily import it in a page or component
2. Or copy the example code into your own component
3. Or use them as a reference for component props and patterns
