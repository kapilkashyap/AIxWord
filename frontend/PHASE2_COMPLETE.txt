CUSTOM HOOKS FEATURES
================================================================================

useAPI<T>():
  Purpose: Manage single API call state
  Returns:
    - data: T | null
    - loading: boolean
    - error: string | null
    - execute: (apiCall) => Promise<T | null>
    - reset: () => void
    - clearError: () => void

useMultiAPI<T>():
  Purpose: Manage multiple API calls with individual tracking
  Returns:
    - states: Record<string, ApiState<T>>
    - execute: (key, apiCall) => Promise<T | null>
    - getState: (key) => ApiState<T>
    - reset: (key) => void
    - resetAll: () => void

usePuzzle():
  Purpose: Manage puzzle state and user interactions
  State:
    - puzzle: Current puzzle data
    - userCells: User's cell values
    - selectedCell: Currently selected cell
    - currentDirection: Current word direction
    - activeClue: Currently active clue
    - cellStates: Cells with UI state
    - gridState: Complete grid state
    - isComplete: Whether puzzle is complete
    - completionPercentage: Completion percentage
  
  Actions:
    - loadPuzzle: Load new puzzle
    - clearPuzzle: Clear current puzzle
    - setCellValue: Update cell value
    - clearCell: Clear cell value
    - resetGrid: Reset all cells
    - selectCell: Select a cell
    - toggleDirection: Toggle direction
    - selectClue: Select a clue
    - setActiveClue: Set active clue
