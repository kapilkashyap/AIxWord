STATE MANAGEMENT
================================================================================

The CrosswordGrid component is designed to work with external state management.
It receives state as props and communicates changes through callbacks.

Required State:
- cells: Cell[]                    // Grid cell data
- selectedCell: {row, col} | null  // Currently selected cell
- currentDirection: Direction      // 'across' or 'down'
- activeClue: {number, direction} | null  // Active clue

Required Callbacks:
- onCellSelect(row, col)           // When user selects a cell
- onCellChange(cells)              // When cell values change
- onDirectionChange(direction)     // When direction toggles
- onActiveClueChange(clue)         // When active clue changes

INTEGRATION WITH PUZZLE DATA
================================================================================

The component expects puzzle data in the following format:

cells: Array of Cell objects with:
  - row: number
  - col: number
  - value: string | null
  - is_blocked: boolean
  - number: number | null

cluesAcross/cluesDown: Array of Clue objects with:
  - number: number
  - direction: 'across' | 'down'
  - text: string
  - answer: string | null
  - start_row: number
  - start_col: number
  - length: number
