AIxWord Frontend - Quick Start Guide
=====================================

This guide will help you get the React frontend up and running quickly.

PREREQUISITES
-------------
- Node.js 18+ and npm installed
- Backend API running on http://localhost:8000

SETUP STEPS
-----------

1. Install Dependencies
   
   cd frontend
   npm install
   
   This will install all required packages including:
   - React 18+
   - TypeScript
   - Vite
   - Tailwind CSS
   - Axios
   - Vitest

2. Configure Environment (Optional)
   
   cp .env.example .env
   
   The default configuration should work if your backend is on port 8000.
   Edit .env if you need to change the API URL:
   
   VITE_API_BASE_URL=http://localhost:8000

3. Verify Setup
   
   node verify_setup.js
   
   This will check that all files are in place and configurations are correct.
   You should see all green checkmarks.

4. Start Development Server
   
   npm run dev
   
   The application will start on http://localhost:5173
   Open this URL in your browser.

5. Verify Application
   
   You should see the AIxWord welcome screen with:
   - Header: "🧩 AIxWord"
   - Subtitle: "AI-Powered Interactive Crossword Puzzles"
   - Empty state message

TROUBLESHOOTING
---------------

Problem: Port 5173 already in use
Solution: Kill the process or change port in vite.config.ts

Problem: Cannot connect to backend
Solution: 
  1. Ensure backend is running: cd ../backend && python run_server.py
  2. Check backend is on port 8000
  3. Verify VITE_API_BASE_URL in .env

Problem: TypeScript errors
Solution: Run npm install again to ensure all types are installed

Problem: Tailwind styles not applying
Solution: 
  1. Check tailwind.config.js content paths
  2. Ensure index.css imports Tailwind directives
  3. Restart dev server
